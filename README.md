# Simple-C-Hash-SHA256

Codigo simples para gerar uma Hash Sha256 usando a lib do Openssl

para compilar o arquivo

- gcc main.c -o main -lcrypto

# Adicionando comandos
- compare arquivos rapidamente com -c
- codifique mensagens com -a
- exporte hash de arquivos com -e
- compare duas hashs em arquivos de texto com -C
